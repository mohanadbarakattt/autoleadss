# AutoLeadss Membership Systems

AutoLeadss turns repeat-service businesses into membership businesses. Each client receives a premium bilingual storefront, online package sales, customer QR passes, a mobile staff scanner, and a focused owner dashboard.

The commercial model is deliberately simple: a reusable product foundation, deployed and branded separately for each merchant so their domain, payment account, customer data, and code can be handed over cleanly.

```bash
npm install
npm run dev
```
